# Biance Vision 用户操作手册 v2（对应 v0.9.x 界面）

> 本手册按 **v0.9.x** 当前线上界面撰写（多语言 + 翻译 Agent 版本），与 [user-manual.md](user-manual.md)（v0.8 版）并存。
> 这份手册回答两个问题：**拿到网址后怎么用**，以及**怎么用这套 AI 研究工具拿到三个场景的投资建议**。
> 本系统是**研究工具**：不连接你的交易账户、不会自动下单、不承诺任何收益。所有结论都是「如果…则…」的条件式研究意见，最终决策与操作都在你自己。

## 一、快速上手：从收到网址到看到行情

### 1.1 打开网址，登录

1. 用浏览器（推荐 Chrome / Edge / Safari 最新版）打开线上地址：**https://btcpilot.duckdns.org/**
2. 系统会自动跳到**登录页**。输入运营发给你的**用户名和密码**，点登录。
   - 本系统**不开放自助注册**，没有账号就找发放网址的人要。
   - 登录一次，**7 天内**不用再登（同一浏览器）。
3. 登录成功后进入「大盘总览」页，看到实时行情就说明一切正常。

### 1.2 认识界面（v0.9 新增：中英双语）

登录后先看五个固定元素：

| 位置 | 元素 | 作用 |
| --- | --- | --- |
| 顶部导航 | **大盘总览 / 价格行为 / 研究终端** 三个标签 | 三大页面，点击切换 |
| 顶部右侧 | 连接状态（实时连接 / 连接中 / 已断线 · 重连中）、铃铛、喇叭 | 行情连接是否正常；系统通知与提示音开关 |
| 顶部右侧 | **🌐 语言按钮（v0.9 新增）** | 中英文一键切换，详见 1.4 |
| 右上角 | 你的用户名（点开是菜单） | 切换涨跌配色、唤起 AI 助手、退出登录 |
| 右下角 | 圆形机器人悬浮按钮（**AI 助手**） | 任何页面都能点开对话，直接描述问题即可发起研究 |

**整个系统已双语化**：导航、行情页、研究终端、结果卡、图例帮助全部中英对照；语言选择会被记住，刷新和下次打开都保持。

### 1.3 三个页面各干什么

- **大盘总览 / Market Overview**：看行情。BTC/ETH 快价卡、市场情绪（涨跌家数）、24h 总成交额、K 线图（六档周期）、成交额前 150 交易对列表（可搜索/排序）。英文界面下成交额自动用 T/B/K 国际单位。
- **价格行为 / Price Action**：学方法。Al Brooks 结构（摆动点、腿、内外包、信号、状态条、EMA20）直接标注在 K 线上；右侧信号清单带规则出处，点「? 图例与规则」有完整双语速查；「🤖 AI 解读」可把当前结构一键发给 AI 按 Brooks 框架解读。**只做结构识别，不做预测**。
- **研究终端 / Research Terminal**：要建议。三个投资研究场景都在这里完成，也是本手册第二章的主角。

### 1.4 切换界面语言（v0.9 新增）

1. 点顶栏右侧的**地球图标**按钮，出现两个选项：**简体中文 / English**。
2. 点选后整个界面立即切换（无需刷新），选择自动记住——下次打开、换浏览器标签都不变。
3. 语言切换是**全局联动**的：K 线图内置文案、时间格式、成交额单位、Brooks 术语解释、研究信号文案（如「冲刺↑」↔「Spike↑」）都会跟着切换；正在看的研究结果重新加载后同样以当前语言展示。

> 语言只影响界面显示，不影响研究逻辑与数据。

## 二、三个场景：一步步拿到投资建议

三个场景都在**研究终端**完成。当前有**两版界面**（功能与结论完全一致，按喜好选用）：

| | 经典版（默认） | 新版工作台 |
| --- | --- | --- |
| 地址 | `/research` | `/research?ui=dev`（直达链接：**https://btcpilot.duckdns.org/research?ui=dev**） |
| 布局 | 顶栏场景栏 + 左栏（持仓/报价/历史）+ 中栏 K 线 + 右栏对话 | 左侧会话导航 + 中央对话流 + 右侧可拖宽的证据/图表面板 |
| 互相切换 | 顶栏「体验新版」链接 | 顶栏「切换旧版」链接 |
| 详见 | 2.1 | 2.2 |

### 2.1 经典版研究终端布局

- **顶栏**：场景下拉（现货 / USDT 永续 / 事件合约）、交易对输入框、研究期限下拉（10 分钟 / 30 分钟 / 1 小时 / 1 天 / 1 周（研究模式））、行情数据时间与连接状态。
- **左栏**：三块列表——「持仓（手动确认）」「事件报价」「历史研究」。**点某一行的意思是「选中它」**（选中行高亮）：选中的持仓/报价会关联到下一次研究；点历史研究某条记录则是回看当时结果。
- **中栏**：K 线图（带 Brooks 结构标注），结论关键价位画成虚线；回看历史研究时图表定格在当时的冻结快照，看完点「回到实时」恢复。
- **右栏**：对话框。所有研究通过「发一句话」发起；对话面板头部「发起研究 / 录入」按钮打开录入表单弹层。

> 通用节奏：**选好场景和交易对 →（按场景）录入并在左栏选中持仓或报价 → 在对话框发一个问题 → 看运行气泡的进度 → 读结果卡**。

### 2.2 新版工作台（`?ui=dev`，v0.9 推荐体验）

打开 **https://btcpilot.duckdns.org/research?ui=dev**（或在经典版顶栏点「体验新版」）：

- **左侧会话导航**：「开启新对话」按钮 + 按日期分组的历史对话列表（今天/昨天/最近 7 天/更早），点任意一条恢复完整上下文；底部有行情大盘 / 价格行为的快捷入口与账号区。
- **中央对话流**：以对话为绝对主角。首次进入是欢迎页（含按场景推荐的问题，点一下即填入）；发出研究后，运行进度气泡、结果卡、追问按钮全部内联在消息流里。
- **输入区**（对话流底部）：场景三标签（现货研究 / USDT 永续 / 事件合约）+ 交易对 + 研究期限 + 发送框；永续/事件场景下有「持仓 / 风险」「报价 / 结算」按钮快速关联或录入数据。
- **右侧研究资料面板**：研究结果出现后，点消息流里的「查看证据 ↗ / 查看图表 ↗」展开；面板可在「引用与证据」和「结构图表」间切换，宽度可拖动调整；手机上自动收进「图表 / 对话 / 证据」三个标签。
- **每条消息下可能有「🌐 翻译」小按钮**：界面语言与消息语言不同时出现，点一下原文下方展开译文（详见第三章）。

两版界面**共用同一条会话数据**：在经典版发起的研究，切到新版工作台照样能看、能继续追问。

### 2.3 场景一：现货结构研究 —— 「现在是什么结构？这个概念什么意思？」

适合：想学 Brooks 方法、问概念、了解某个币当前的盘面结构。不涉及持仓和费用。

1. 场景选 **现货 / Spot**，选好交易对（如 BTCUSDT）与期限（如 1 小时）。
2. 在对话框输入问题，回车。可以直接照抄：
   - `BTC 现在是什么结构？还能追多吗？`
   - `什么是铁丝网（Barb Wire）？怎么识别？`
   - `H2 是什么？现在算 H2 吗？`
3. 对话流里出现**运行气泡**，实时显示八个研究阶段（意图规划 → 行情快照 → 结构计算 → 知识检索 → 产品分析 → 反证审查 → 综合解释 → 风险校验 → 发布），一般几十秒内完成；等不及可点气泡上的「取消」。
4. 完成后出现**结果卡**：决策徽章 + 综合解释（直接回应你的问题，带 [k] 引用编号）+ 论断（事实/解读分开）+ 证据列表。
   - **点证据编号**：行情类证据在 K 线上用琥珀色竖带定位；知识类证据打开来源抽屉，**定位到 Brooks 原文页码/图号**。
   - 结果卡下方有**追问按钮**（如「查看本研究的证据」「换个周期再跑一次」），一键执行，不用重新打字。

### 2.4 场景二：USDT 永续持仓建议 —— 「我的多单还能拿吗？」

适合：你在币安有（或打算开）USDT 永续仓位，想要带盈亏测算的条件式计划。

1. 场景选 **USDT 永续**，选好交易对和期限。
2. **录入持仓**（两种途径选一）：
   - 途径 A：点「发起研究 / 录入」（新版工作台是「持仓 / 风险」按钮）打开「录入持仓（App 抄录）」表单；
   - 途径 B：直接在对话框说一句**带方向和数量**的话，如 `做多 0.01 BTCUSDT，帮我记入持仓`，AI 弹出**持仓确认卡**；缺的字段它列出来让你补（例如回 `入场 60000，最多亏 200`），核对无误点「确认写入」，不要了回复「取消」。
3. 表单字段照着币安 App 持仓页抄：

   | 字段 | 怎么填 |
   | --- | --- |
   | 方向 | 做多 / 做空 |
   | 数量 | 持仓数量（如 0.01） |
   | 开仓价 | App 显示的开仓均价 |
   | 杠杆 | App 显示的杠杆倍数 |
   | 保证金模式 | 逐仓 / 全仓 |
   | 风险预算 | 这笔单最多能接受亏多少钱（USDT） |
   | 止损价 | 计划止损位，可留空 |
   | 强平价 | **从 App 抄录**；不知道就留空（系统不瞎估） |

4. **让录入的持仓被选中关联**（经典版在左栏点该行；新版工作台在「持仓 / 风险」弹层顶部的下拉里选）。不选也能研究，但按「无持仓一般结构研究」处理，盈亏矩阵和仓位上限不算。
5. 提问示例：`多头持仓是否继续持有？` `回调二次进场怎么等？` `现在能开空吗？止损放哪？`
6. 读结果卡：**决策徽章**（做多/做空/等待/持有/减仓/退出/条件参与/请重新确认持仓）+ **条件情景**（条件/应对/失效三段）+ **计划盈亏矩阵（taker 双边费用）** + **仓位上限与触发约束** + **强平价**（只有你抄录过才显示）。
7. 持仓有「保质期」：过期后左栏/关联按钮会标「已过期需重确认」，重新确认一次再问。

### 2.5 场景三：事件合约 EV 研究 —— 「这张单子值得买吗？」

适合：你在币安 App 玩**事件合约**。官方没开放接口，报价需**手动从 App 抄录**。

1. 场景选 **事件合约**，选好交易对。
2. 打开「录入事件报价（App 抄录）」表单：

   | 字段 | 怎么填 |
   | --- | --- |
   | 执行价 | App 显示的执行价 |
   | 到期方式 | **还没买**选「录入时刻 + 期限」；**已经买了**必须选「App 固定到期时刻」照抄订单页时间 |
   | 投入金额 / 总返还 | 投入本金 / 到期返还总额（**含本金**，不是净收益） |
   | 方向 | 到期高于 / 低于执行价 |
   | 结算参考价 | App 展示值，可留空 |
   | 订单状态 | 参与前（预览价 60s 时效）/ 已提交（固定值） |
   | 事件风险预算 | 这一单最多可接受损失（**必填**，不填参与建议被直接拒绝） |

3. 让报价被选中关联（行上显示「剩 X 分」「期限匹配/未匹配」）。不选报价研究照跑但 EV 不可计算。
4. 提问示例：`当前结构支持到期高于执行价吗？` `10 分钟后高于 60000 的事件合约值得参与吗？`
5. 读结果卡「事件合约评估」区块：**模型概率**（没就绪时明确显示不可用及原因，不编数）、**盈亏平衡胜率**（投入÷总返还）、**期望净收益 EV**、**倒计时**。选 **1 周**期限时有显著的「研究模式（非币安事件合约产品）」标识。
6. **到期后**：系统用分钟级已收盘 K 线给出「研究估算」；你在左栏（或工作台「报价 / 结算」弹层）对应报价上点「确认结算」（高于/低于/平价）录入真实结果，估算与真实分开统计。

## 三、翻译：三种用法（v0.9 新增）

系统内置专业翻译能力，按 Brooks 术语表翻译（冲刺=spike、楔顶=wedge、二次进场=second entry、H1~H4/EMA20 等保留原文），交易对代码、数字、价格、公式原样保留。

### 3.1 消息翻译按钮（最常用，X/Twitter 式交互）

对话流里**语言与界面语言不同的消息**下方，会出现一个「🌐 翻译 / Translate」小按钮：

1. 点按钮 → 按钮变为「翻译中…」→ 原文下方内联展开译文（原文保留在上）。
2. 译文底部有来源标注：「翻译自 中文 · 由大模型翻译」（若由离线引擎产出会标注「由离线引擎（Argos）翻译」，术语译法可能与主引擎略有差距）。
3. 点「显示原文」收起译文；再点「显示译文」重新展开。
4. 翻译失败时按钮变红色「翻译失败，点击重试」——两个翻译引擎都不可用时系统会明确告知，**不会给出不可靠的机器译文**。

> 规则与 X 一致：消息语言与界面语言相同时不出现按钮。例：界面是英文时，中文研究结论下方有 Translate 按钮；切回中文界面后，英文消息下方反而出现「翻译」按钮。

### 3.2 会话里直接下翻译指令

在研究终端或 AI 助手里直接说：

- `把下面这段翻译成英文：BTC 多头冲刺后进入通道，回调至 EMA20 出现 H2…`
- `translate this to Chinese: The bull spike entered a channel...`

AI 自动识别翻译意图（不启动研究），直接回复译文。没写明目标语言时自动判断：中文内容译成英文，其他译成中文。也支持日/韩/法等语言（此时仅大模型引擎可用）。

### 3.3 AI 助手里的斜杠命令

AI 助手聊天框输入：

- `/translate english BTC 冲刺通道延续` （或 `/translate chinese ...`）
- 简写：`/trans`、`/fy`

## 四、背后的 AI Brooks 逻辑（原理速览）

- **三层读法**：单根 K 线特征（趋势棒/十字星/内外包）→ 结构（摆动点、腿、HH/HL 序列）→ 信号生命周期（成立 setup → 触发 → 失效分开记录）。
- **因果纪律**：只用**已收盘** K 线；每个结构带 `knownAt` 时间戳，历史复盘严格只用当时可见的信息。
- **条件式结论，不是指令**：结论都是「如果价格…则…；跌破…则失效」，且同时列支持证据与反对证据（专门的「反证审查」环节唱反调）。
- **各司其职**：Brooks 结构引擎定方向与失效位；盈亏/费用/EV/仓位上限全部由后端代码按公式计算（AI 不被允许编数字）；AI 只负责组织成人话并引用证据。
- **概率不拍脑袋**：事件合约概率唯一来自统计预测模型；模型未就绪/期限不匹配/数据过期时明确显示不可用，不编数。

更多展开见 [user-manual.md](user-manual.md) 第三章（原理与数据来源说明同样适用）。

## 六、这些「异常」其实是正常的

| 界面表现 | 含义 | 怎么办 |
| --- | --- | --- |
| 顶栏标「数据陈旧 / Data stale」 | 行情停更或网络断 | 看连接状态；陈旧期间结论打 stale 标，恢复后重问 |
| 概率一行显示「不可用」及原因 | 模型训练中/期限未验证 | 参考结构证据与盈亏平衡胜率 |
| 事件场景提示先录入报价 | 官方无接口 | 按表单抄录 App 数据并选中关联 |
| 结论卡「证据不足」 | 证据链不完整，拒绝给方向 | 按卡片列的缺失项补信息 |
| 运行气泡 failed / cancelled | 出错/你主动取消 | 失败面板「重新发起（相同标的与期限）」一键重试 |
| K 线停在过去不动 | 在回看历史研究的冻结快照 | 点「回到实时」恢复 |
| 持仓标「已过期需重确认」 | 确认时间太久 | 重新抄录确认一遍再问 |
| 翻译按钮显示「翻译失败」 | 两个翻译引擎暂不可用 | 点按钮重试；持续失败联系管理员 |
| 界面上出现英文原词（如 published） | 运行状态词暂不翻译 | 正常，不影响使用 |

## 七、常见问题 FAQ

**Q：网址打不开 / 一直跳登录页？**
A：核对网址 `https://btcpilot.duckdns.org/`（注意 https）；登录态 7 天有效，过期重登即可。

**Q：在国内能访问吗？**
A：不能。本服务仅面向海外地区开放，大陆来源访问会被拦截（看到拦截提示页属正常）。

**Q：切换语言后研究结论会变吗？**
