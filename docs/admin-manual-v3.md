# Biance Vision 管理后台操作手册 v3（对应 v0.16.x 界面）

> 适用版本：v0.16.2 及以上（2026-10-24）。
> **管理后台入口（v0.16 起）**：**https://btcpilot-admin.duckdns.org** ——主域名上的 /admin 已彻底移除（双系统拆分：管理端独立进程/独立域名/独立数据库权限）。
> v3 相对 v2 的重大变化：①入口改为管理域名+两层登录；②知识库页全新（上传队列/批量/版本回滚/解析日志下钻）；③用户/会话/配置全部以 PostgreSQL 为唯一真源。

---

## 一、进入管理后台（两层门）

### 1.1 第一层：浏览器账密框（Basic Auth）
1. 打开 https://btcpilot-admin.duckdns.org ，浏览器弹**原生账号密码框**。
2. 输入 Basic Auth 账号（bvadmin）和密码（保存在你的密码管理器）。这是网络层门禁，挡住一切扫描器。

### 1.2 第二层：系统登录
1. 过第一层后进入管理端登录页。
2. 用**超管账号**（admin）登录。普通账号在此被拒（管理认证只在管理端进程签发）。

### 1.3 六页导航
登录后左侧/顶部菜单：**管理面板 / AI 全景 / 知识库 / Agent / 提示词 / 评测**，另有「AI 档案配置」按钮（多档案/绑定用户）。

## 二、知识库管理（v0.16 全新界面，核心章节）

### 2.1 上传资料（队列化）
1. 点右上「**+ 上传资料**」→ 弹窗内三个 Tab：**文件 / URL / 清单**。
2. **文件 Tab**：把 PDF/DOCX/TXT/MD/HTML 拖入（或点击选择，可多选）。
   - 入队时自动做**三道校验**：格式、大小（≤50MB）、同名同大小查重；再按**内容指纹查重**（与库内已有资料比对，重复的标黄不会重复上传）。
   - 底部选**来源等级**（官方/官方衍生/社区）与**访问级别**（公开/购买/会员——购买/会员资料发布后普通用户检索不可见）。
   - 点「**开始上传**」：逐文件显示进度百分比；上传中点「**取消**」会自动清理本次已传文件（回滚，不留半传残留）；全部成功后「完成」关闭。
   - 商业书籍请只上传你有使用权的文件。
3. **URL Tab**：粘贴公开资料网址 → 导入（自动抓取；有访问限制的网址会如实失败，不绕过）。
4. **清单 Tab**：入口跳转「清单管理」弹窗（见 2.6）。

### 2.2 看解析进度与状态
上传后回到卡片列表：
- **状态徽章**：待解析（灰）→ 解析中（蓝，脉冲）→ 待发布（琥珀）→ 已发布（绿）/ 失败（红边+原因）。
- 解析中的文档每 2 秒轻量刷新（有变化才全刷）；**若顶部出现黄色条「解析队列不可用：worker 未运行」**，说明解析进程挂了——新上传会排队等待，恢复后自动继续。
- **失败下钻**：点失败徽章或「日志」→ **解析日志抽屉**，展示本轮解析的每个阶段（入队→解析批次→切分→向量化→完成/失败）与耗时，失败阶段红色高亮——可据此判断是文件问题还是服务问题，修复后点「重试」。

### 2.3 预览与发布
1. 点任意卡片 → **预览抽屉**：
   - 「分块」页签：解析切块全文（渲染后的富文本）；
   - 「原文」页签：PDF/HTML 原生渲染，DOCX 提供下载。
2. 状态为「待发布」时，抽屉内点「**发布上线**」→ 该资料进入当前知识版本，**检索立即可见**。
3. 也可勾选多个卡片用底部批量栏「**发布**」（部分失败会汇报「成功 N · 失败 M(原因)」）。

### 2.4 删除（两段式）
- 单删/批量删都会弹确认：**默认=归档**（移出当前发布版本、保留数据可追溯）；需要彻底清除时勾选「强制删除」（分块/原始文件/版本引用一并清理，不可恢复）。
- 正在解析中的文档删除会额外提示「将取消解析任务并强制删除」。

### 2.5 版本历史与回滚
1. 列表底部「**已发布版本 vN**」→ 弹窗列出全部知识版本（版本号/时间/包含文档数/触发人）。
2. 当前版本标「生效中」；任一历史版本点「**切回此版本**」→ 确认后**以旧集合发布一个新版本**（历史记录不可变，旧引用永远有效；随时可再切回）。

### 2.6 清单批量导入
「清单导入」按钮 → 弹窗展示维护清单（docs/references/knowledge-source-manifest.json）全部条目及**导入状态**（待导入/已导入/跳过/失败+原因）：
- 「从默认清单重新同步」：把最新清单条目入库（不抓取内容）；
- 勾选条目「导入」或对失败条目「重试」：逐条自动抓取（仅公开+自动抓取类条目；需手动上传类保持指引）。

### 2.7 检索调试 / 规则卡 / 案例窗
知识库页下方三个面板：
- **检索调试**：输入查询看混合检索全链路打点（词项召回/向量召回/RRF 融合/权限过滤留痕）——验证某资料"为什么能/不能被搜到"用这里。
- **规则卡**：知识概念卡片的草拟→发布→版本治理。
- **案例窗**：标注案例的构建/发布/下架。

## 三、管理面板：用户与聊天管控

- **用户列表**：每行显示角色、聊天管控策略、**当日用量**（v0.16 起实时读数据库，跨端即时准确）、最近活跃。
- 操作：**禁用/解禁 AI 助手**、设**每日交互上限**、**一键掐断**（禁用并取消该用户全部进行中的研究）。
- 页面下半部为**审计日志**（会话聚合式：一次登录一条，全部操作挂在会话内）。

## 四、AI 全景

- 各用户 AI 使用统计（会话数/消息数/记忆数/最近活跃）。
- 点开任一用户：完整 AI 会话记录、长期记忆列表、生效档案——排查"用户为什么得到这样的 AI 回答"用这里。

## 五、AI 档案配置（导航栏按钮）

- 多档案管理：每档=接口地址/API Key/模型/温度/每日限额/追加提示词；`default` 为总开关档案。
- **绑定用户**：指定用户走指定档案（一个用户只能绑一个）。
- 「测试连通性」校验接口/Key/模型名；「❗」查看该档案当前生效的完整系统提示词。
- 密钥只存服务端，前端永远只显示掩码。

## 六、Agent / 提示词 / 评测

- **Agent**：研究管线能力配置（LLM/搜索/解析引擎开关与参数）+ Agent 版本发布/回滚。
- **提示词**：LLM 模板的版本化治理（草稿→发布→回滚，含场景标签）。
- **评测**：数据集管理+触发评测运行+报告查看（67 条基线评测保护回退）。

## 七、故障速查

| 现象 | 处置 |
|---|---|
| 管理域名打不开/弹框循环 | 先确认 Basic Auth 密码；仍不行查 VPS Caddy 服务（ LOCAL_NOTES 排障节） |
| 登录页输 admin 被拒 | 管理端只认超管账号且密码独立于 Basic Auth；连败多次会临时锁定 15 分钟（跨域名共享计数） |
| 知识库黄条「解析队列不可用」 | worker 容器停了：SSH 上 VPS `docker start biance-vision-worker`（或等自动重启） |
| PDF 解析失败「疑似扫描版」 | 换数字版文件，或用离线通道（offline-parse 脚本，见 docs/rag-pipeline-design.md） |
| 主站用户被限流提示 | 在管理面板查看该用户当日用量与限额；限速锁定 15 分钟自动解除 |
