## Features and dependencies

- Configurable membership plans, immutable purchased versions, shared introductory capacity, manual receipts, provisioning, renewal, switching, revocation and explicit legacy migration.
- Separate chat/research AI references, frozen research configuration and atomic daily usage with idempotency/refunds. Existing research rules and legacy access remain compatible.
- Shared configurable polling, user membership progress and renewal contacts, bilingual public pricing with server-rendered initial catalog and browser updates.
- Existing dashboard, queue health, monitoring, knowledge management and all other previously integrated features retained.
- Homepage hero wording and search-specific metadata are separate so the existing category title is not lost.
- Website tests build their shared runtime dependency before loading it. Release assets now include SQL migrations and workspace/deployment dependencies.
- Production's uncommitted CSRF/subject-HMAC environment forwarding was inspected and backported to both deployment overlays, preserving the existing secrets without publishing values.

The four initial plans remain drafts and the introductory campaign remains disabled until the administrator confirms AI references and publishes them. Existing users are not automatically migrated or assigned payments.
