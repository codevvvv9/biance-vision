# Biance Vision 管理后台操作手册 v2（对应 v0.9.x 界面）

> 本手册按 **v0.9.x** 当前界面撰写（六页后台 + 提示词治理 + 双语 + 翻译 Agent），与 [admin-manual.md](admin-manual.md)（v0.8 版）并存；v0.8 手册中未变化的细节（知识库/评测等操作）在此只做索引。
> 面向对象：超级管理员（超管）。后台所有页面与接口仅超管可见可用。
> 本手册只讲页面操作；服务器、命令行、数据库事项联系开发人员。
> 配套文档：最终用户视角见 [user-manual-v2.md](user-manual-v2.md)。

## 一、先读这里（3 分钟上手）

### 1.1 超管账号与登录

系统不开放自助注册。超管账号由部署系统的开发人员创建交付；新增账号、重置密码同样联系开发人员。

### 1.2 怎么进管理后台

1. 超管账号登录。
2. 点右上角「用户名 超管」展开下拉菜单。
3. 菜单**平铺列出六个后台页面**，点哪个进哪页：

| 菜单项（副标题） | 这页管什么 | 本手册章节 |
| --- | --- | --- |
| 管理面板（用户 / 日志） | 用户列表、禁用与每日限量、掐断、操作日志 | 第三节 |
| AI 会话（上下文 / 记忆） | 研究会话追踪、生效配置、长期记忆 | 第四节 |
| 知识库（导入 / 发布 / 检索调试） | 资料导入、解析发布、检索调试、规则卡、案例窗 | v0.8 手册第六节（操作未变） |
| Agent 配置（能力 / 版本 / 回滚） | 研究流水线的五类模型能力、版本发布与回滚 | v0.8 手册第七节（操作未变） |
| **提示词与文案（模板版本 / 免责 / 输入配置）**（v0.8.x 起） | **八个 LLM 提示词模板的版本化治理**、免责文案、输入面板配置 | 第五节 |
| 评测与模型（数据集 / 训练 / 指标） | 评测数据集、评测运行、概率模型训练 | v0.8 手册第八节（操作未变） |

进入后台后顶部有同样的六页导航，左上角「← 返回主站」回行情页。

### 1.3 界面语言（v0.9 新增）

整个系统（含后台导航与菜单）支持中英文：右上角**地球图标**一键切换，选择自动记住。后台各页面的表头/按钮/提示同步切换；数据内容（用户名、会话标题、日志明细等用户产生的文本）保持原文。

### 1.4 两套 AI 配置，别搞混（最重要的一节）

| | 「AI 设置」弹窗 | 「Agent 配置」页 |
| --- | --- | --- |
| 从哪进 | 用户菜单 →「AI 设置」 | 用户菜单 →「Agent 配置」 |
| 管什么 | 用户侧 **AI 助手聊天**（右下角机器人，**含 /translate 翻译命令**） | **研究终端**研究流水线 + 知识库向量化/精排/搜索 |
| 按谁生效 | 按「配置档案」绑定用户，未绑定走 `default` | 全站统一（当前发布 Agent 版本或全局设置） |
| 密钥 | 直接粘贴 API Key（回显打码） | 只填密钥引用名 |

一句话：**用户聊天/翻译不工作 → 查「AI 设置」；研究跑不动/检索不行 → 查「Agent 配置」。**

## 二、常见任务速查

| 我要…… | 去哪 |
| --- | --- |
| 让大家能用 AI 助手聊天（含 /translate） | 「AI 设置」配好 default 档案（v0.8 手册第四节） |
| 限制/禁用某用户、掐断进行中研究 | 「管理面板」用户行操作（v0.8 手册第三节） |

## 三、管理面板：用户与聊天管控

操作与 v0.8 手册第三节一致（用户列表三态展示、复制/禁用/每日上限/掐断四操作、操作日志按会话聚合）。v0.9 补充两点：

1. **翻译计入每日交互**：用户的每次消息级翻译（点消息下的「🌐 翻译」按钮）与 `/translate` 命令都计入同一「每日上限」口径——防刷逻辑与聊天一致，无需单独配置。
2. 界面文案随语言切换（表头「用户/角色/聊天」↔「User/Role/Chat」等），数据含义不变。

## 四、AI 会话：排查用户侧 AI 行为

操作与 v0.8 手册第五节一致。v0.9 排查翻译问题时多看两个审计字段：

- 研究会话消息展开后，**意图标签**出现 `translate` = 该条走了翻译链路；
- 消息详情带 **promptRefs**（提示词引用）= 大模型主翻使用的模板版本（Argos 离线兜底与降级路径无 promptRefs，属正常）。

## 五、提示词与文案：LLM 模板的版本化治理（v0.9 重点）

这页管"提示词"：所有 LLM 调用点的系统提示词集中版本化管理。**草稿可编辑 → 发布不可变 → 回滚 = 指针切回历史版本**；当前生效版本由指针决定。

### 5.1 八个模板各管什么

| 模板 | 调用点 | 说明 |
| --- | --- | --- |
| intent-classifier | 会话层 | 意图分类（LLM 纠偏确定性结果）。当前 **v2**（含 translate 枚举） |
| counter-reviewer | run 内 | 反证归纳，要求每行 [k] 证据编号 |
| news-attribution | 会话层 | 新闻归因附答 |
| concept-teaching | 会话层 | 概念教学附答 |
| query-rewrite | run 内 | 检索查询改写变体 |
| synthesis-writer | run 内 | 受约束综合解释（只引用已计算事实/条件/证据） |
| memory-extraction | run 发布后 | 研究长期记忆提取 |
| **translate**（v0.9 新增） | 会话层 | 翻译主翻：内置 Brooks 术语表（冲刺=spike、楔顶=wedge top/bottom、二次进场=second entry、内包线=inside bar、H1~H4/EMA20/Always In 不译），要求保留交易对代码/数字/markdown 结构，只输出译文 |

> Argos 离线翻译兜底**不经提示词**（本地神经翻译引擎），无需在此配置。

### 5.2 标准操作：调整一个提示词

1. 「新建草稿」区：模板下拉选名（带用途说明）→ 内容框粘贴全文（1~20000 字）→ 可填备注（如"调整了术语表"）→ 点创建。
2. 版本列表找到草稿 →「编辑」可再改 →「发布」立即生效（会话与后续 run 即用新版本；**发布后内容不可改**）。
3. 出问题：点历史版本旁「回滚到此」，指针切回。

同名模板可按 (name, scene) 场景差异化，`全局` 为缺省——一般场景用全局即可。

### 5.3 红线：新增意图必须同步升级 intent-classifier

给系统加新意图（如本次的 translate）时，**只改代码不够**：数据库指针指向的旧分类器模板没有新枚举，LLM 会把新请求「纠偏」到错误意图（实测：翻译请求曾被分到 system）。正确做法：

1. 代码里加意图与确定性正则；
2. 在本页为 intent-classifier **新建草稿（枚举加入新意图）→ 发布为新版本**；
3. 验证：发一条新意图消息，在「AI 会话」页确认意图标签正确。

### 5.4 免责文案与输入面板配置（页面右侧）

- **免责文案**：结果卡底部追加的声明，按产品三条（perp / event / common），保存**即时生效**无需重启。
- **输入面板配置**：研究输入框的占位文案与建议问题数（JSON：`chatInput.scenes.<场景>.placeholder / suggestionLimit`），非法结构服务端拒绝。修改后新对话立即生效。

## 六、翻译能力运维（v0.9 新增）

用户侧三种翻译入口（消息按钮 / 会话指令 / `/translate` 命令）共用一条**三级降级链**，运维要点：

| 层级 | 依赖 | 怎么确认它活着 |
| --- | --- | --- |
| 1. 大模型主翻 | 「AI 设置」的 chat 模型（同用户聊天档案） | AI 助手能聊 = 主翻可用；翻译结果标注「由大模型翻译」 |
| 2. Argos 离线引擎 | research-py 服务 + zh↔en 语言包（服务器本地，不走外网 API） | 找开发人员查 `/health` 的 `argosPairs` 字段（应为 `["en->zh","zh->en"]`）；翻译结果标注「由离线引擎（Argos）翻译」 |
| 3. 显式降级 | — | 用户看到「翻译能力暂不可用」= 两级都挂了，不伪造译文 |

- Argos 仅支持**中↔英**；目标语言是日/韩/法等时只有大模型路径，模型挂了直接降级提示（设计行为）。
- 主翻给大模型的等待时间较长（最长 90 秒，自托管模型排队波动大）；用户侧「翻译中…」状态正常可持续几十秒。
- 翻译消息在「AI 会话」页带 `translate` 意图标签，可逐条审计。

## 七、限量与禁用一页通

与 v0.8 手册第九节一致：用户级每日上限（管理面板）与档案级每人每日次数（AI 设置）两层独立、同时生效、取严；翻译计入用户级口径。

## 八、常见问题与故障排查（v0.9 增补）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 用户点「翻译」一直转圈最后失败 | 大模型不可用且离线引擎缺语言包/服务未起 | 先确认 AI 助手聊天是否正常；持续失败联系开发人员查 research-py |
| 翻译请求被当成普通聊天/问候回复 | 分类器模板版本落后（缺 translate 枚举） | 「提示词与文案」确认 intent-classifier 生效版本 ≥ v2，落后则发布新版本 |
| 译文术语不对（如 H2 被翻译掉） | translate 模板被改坏 | 回滚 translate 模板到 v1（内置术语表版） |
| 切换语言后个别地方仍显示中文 | 管理后台页面内部文案暂未双语（分批迁移中） | 不影响功能；清单由 `pnpm check:i18n` 跟踪 |
| 其余（登录/数据/研究失败/知识库） | — | 见 v0.8 手册第十节排查表 |
