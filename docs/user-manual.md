# Biance Vision 使用手册（用户版）

> 这份手册回答两个问题：**拿到网址后怎么用**，以及**怎么用这套 AI 研究工具拿到三个场景的投资建议**。
> 本系统是**研究工具**：它不连接你的交易账户、不会自动下单、不承诺任何收益。所有结论都是「如果…则…」的条件式研究意见，最终决策与操作都在你自己。

---

## 一、快速上手：从收到网址到看到行情

### 1.1 打开网址，登录

1. 用浏览器（推荐 Chrome / Edge / Safari 最新版）打开线上地址：**https://btcpilot.duckdns.org/**
2. 系统会自动跳到**登录页**。输入运营发给你的**用户名和密码**，点登录。
   - 本系统**不开放自助注册**，没有账号就找发放网址的人要。
   - 登录一次，**7 天内**不用再登（同一浏览器）。
3. 登录成功后会进入「大盘总览」页，看到实时行情就说明一切正常。

### 1.2 认识界面

登录后先看四个固定元素，记住它们就够用了：

| 位置 | 元素 | 作用 |
| --- | --- | --- |
| 顶部导航 | **大盘总览 / 价格行为 / 研究终端** 三个标签 | 系统的三大页面，点击切换 |
| 顶部右侧 | 连接状态（实时连接 / 连接中 / 已断线 · 重连中）、铃铛、喇叭 | 行情连接是否正常；系统通知与提示音开关 |
| 右上角 | 你的用户名（点开是菜单） | 切换涨跌配色（红涨绿跌 / 绿涨红跌）、唤起 AI 助手（机器人被关掉后也从这里重新打开）、退出登录 |
| 右下角 | 圆形机器人悬浮按钮（**AI 助手**） | 任何页面都能点开对话，直接描述问题即可发起研究 |

### 1.3 三个页面各干什么

- **大盘总览**：看行情。顶部 BTC/ETH/BNB 快价、实时滚动行情条、统计卡片（BTC、ETH、市场情绪、24h 总成交额）、K 线图（1 分 / 5 分 / 15 分 / 1 时 / 4 时 / 日线六档可切换）、成交额前 150 的交易对列表（列表可搜索、可按列排序）。点列表里任意一行，K 线就切到那个币。
- **价格行为**：学方法。把 Al Brooks 价格行为学的结构（摆动点、腿、内外包、信号、趋势/震荡状态条、EMA20）直接标注在 K 线上，右侧有信号清单和规则出处。**它只做结构识别，不做预测**，是理解 AI 建议背后逻辑的窗口。
- **研究终端**：要建议。三个投资研究场景都在这里完成，也是本手册下一章的主角。

## 二、三个场景：一步步拿到投资建议

三个场景都在**研究终端**（顶栏第三个标签）完成。先进去认识一下布局：

- **顶栏**：场景下拉（现货 / USDT 永续 / 事件合约）、交易对输入框（输入币种名或从候选列表选，如 BTCUSDT）、研究期限下拉（10 分钟 / 30 分钟 / 1 小时 / 1 天 / 1 周（研究模式））。
- **左栏**：三块列表——「持仓（手动确认）」「事件报价」「历史研究」。**点某一行的意思是「选中它」**（选中的行会高亮）：选中的持仓/报价会关联到你下一次发起的研究；点历史研究里的某条记录则是回看当时的结果。
- **中栏**：K 线图（带 Brooks 结构标注），结论里的关键价位会画成虚线。K 线周期不用手动选，随研究期限自动切换（如 1 小时期限配 15 分 K 线）；回看历史研究时图表会定格在当时的冻结快照，看完点「回到实时」恢复。
- **右栏**：对话框。所有研究都通过「发一句话」发起；对话面板头部有「发起研究 / 录入」按钮，点开弹层，里面是发起研究输入框和持仓/事件报价的录入表单。

> 通用操作节奏：**选好场景和交易对 →（按场景）录入并在左栏选中持仓或报价 → 在对话框发一个问题 → 看运行气泡的进度 → 读结果卡**。

### 场景一：现货结构研究 —— 「现在是什么结构？这个概念什么意思？」

适合：想学 Brooks 方法、问概念、了解某个币当前的盘面结构。这个场景**不涉及持仓和费用**，是纯结构研究。

1. 顶栏「场景」选 **现货**。
2. 「交易对」输入或选择你想看的币（如 BTCUSDT）；「研究期限」选一个时间尺度（如 1 小时）。
3. 在右侧对话框输入你的问题，回车。可以直接照抄：
   - `BTC 现在是什么结构？还能追多吗？`
   - `什么是铁丝网（Barb Wire）？怎么识别？`
   - `H2 是什么？现在算 H2 吗？`
4. 对话流里会出现一个**运行气泡**，实时显示研究进行到哪一步（意图规划 → 行情快照 → 结构计算 → 知识检索 → 产品分析 → 反证审查 → 风险校验 → 发布），一般几十秒内完成；等不及也可以点气泡上的「取消」。
5. 完成后出现**结果卡**：条件式结论 + 支持证据 + 反对证据。
   - **点证据**：行情类证据会在中栏 K 线上用琥珀色竖带定位到对应的那根 K 线；知识类证据会打开来源抽屉，**定位到 Brooks 原文的页码/图号**。

### 场景二：USDT 永续持仓建议 —— 「我的多单还能拿吗？现在能开吗？」

适合：你在币安有（或打算开）USDT 永续仓位，想要一份带盈亏测算的条件式计划。

1. 顶栏「场景」选 **USDT 永续**，选好交易对（如 BTCUSDT）和期限。
2. **录入持仓**（两种途径，选一即可）：
   - 途径 A：点对话面板头部的「发起研究 / 录入」按钮，打开「录入持仓（App 抄录）」表单；
   - 途径 B：直接在对话框说一句**带方向和数量**的话，比如 `做多 0.01 BTCUSDT，帮我记入持仓`，AI 会弹出**持仓确认卡**；缺的字段它会列出来让你补（例如回一句 `入场 60000，最多亏 200`），核对无误点「确认写入」，不想要了回复「取消」。
3. 表单字段照着币安 App 的持仓页抄：

   | 字段 | 怎么填 |
   | --- | --- |
   | 方向 | 做多 / 做空 |
   | 数量 | 持仓数量（如 0.01） |
   | 开仓价 | App 显示的开仓均价 |
   | 杠杆 | App 显示的杠杆倍数 |
   | 保证金模式 | 逐仓 / 全仓 |
   | 风险预算 | 这笔单最多能接受亏多少钱（USDT） |
   | 止损价 | 你的计划止损位，可留空 |
   | 强平价 | **从 App 持仓页抄录**；不知道就留空（系统不会瞎估，留空就不显示） |

4. **回到左栏，点一下刚录入的持仓行让它高亮选中**——弹层顶部会显示「关联持仓 …」。不选也能发起研究，但会按「未选择持仓：按一般结构研究（无计划盈亏）」处理，盈亏矩阵和仓位上限都不算。
5. 在对话框提问，回车。示例：
   - `多头持仓是否继续持有？`
   - `回调二次进场怎么等？`
   - `现在能开空吗？止损放哪？`
6. 读结果卡：
   - **决策徽章 + 条件情景**：卡片顶部的徽章给出方向倾向（做多 / 做空 / 等待 / 持有 / 减仓 / 退出 / 请重新确认持仓），下面每条「条件情景」写明条件、应对、失效三段；
   - **计划盈亏矩阵（taker 双边费用）**：不同价格到达时你的盈亏（含手续费），另有资金费率情景一栏；
   - **仓位上限**：按你的风险预算算出的最大可开仓位，以及是哪条约束在起作用；
   - **强平价**：只有你从 App 抄录了才显示；没抄就明确不显示，绝不拿个估算值冒充。
7. 持仓信息有「保质期」：超过时效，左栏持仓行会标「已过期需重确认」，结论不再把它当当前事实——行情变了就重新确认一下持仓再问。

### 场景三：事件合约 EV 研究 —— 「这张单子值得买吗？」

适合：你在币安 App 里玩**事件合约**（预测到期时价格高于/低于某个执行价）。注意：币安官方没有开放事件合约的接口，所以报价需要你**手动从 App 抄录**。

1. 顶栏「场景」选 **事件合约**，选好交易对。
2. 点对话面板头部的「发起研究 / 录入」按钮，打开「录入事件报价（App 抄录）」表单，对着币安 App 的事件合约页面抄：

   | 字段 | 怎么填 |
   | --- | --- |
   | 执行价 | App 显示的执行价（strike） |
   | 到期方式 | **还没买**选「录入时刻 + 期限」（10 分钟/30 分钟/1 小时/1 天/1 周）；**已经买了**必须选「App 固定到期时刻」，照抄 App 订单页的到期时间 |
   | 投入金额 | 你投入的本金（stake） |
   | 总返还（含本金） | App 显示的到期返还总额——**是含本金的全额，不是净收益** |
   | 方向 | 到期高于 / 低于执行价 |
   | 结算参考价 | App 展示值，可留空 |
   | 订单状态 | 「参与前（预览价 60s 时效）」或「已提交（固定值，只研究剩余期限）」；选参与前时抄的价 60 秒内有效，过期重新抄一次再发起 |
   | 事件风险预算 | 这一单最多能接受的损失（**必填**，不填参与建议会被直接拒绝） |

   > 为什么「已提交」的单子必须抄固定到期时刻？因为 App 里订单的到期时间在下单瞬间就锁死了。如果按「现在 + 10 分钟」算，一张 9 分钟前买的 10 分钟单会被误认为还有完整 10 分钟，结论就错了。
3. **回到左栏，点一下刚录入的报价行让它高亮选中**——行上会显示「剩 X 分」和「期限匹配 / 期限未匹配」，弹层顶部显示「关联报价 …」。不选报价，研究照跑但 EV 不可计算。
4. 在对话框提问，回车。示例：
   - `当前结构支持到期高于执行价吗？`
   - `10 分钟后高于 60000 的事件合约值得参与吗？`
5. 读结果卡（「事件合约评估」区块）：
   - **模型概率**：卡片顶部「模型 xxx：P(高于执行价) = x%」一行（来自统计预测模型；模型没就绪时这行会明确显示「不可用」及原因，不会编一个数）；
   - **盈亏平衡胜率**：这张单子至少要有多高的胜率才不亏（= 投入 ÷ 总返还，代码计算）；
   - **期望净收益 EV**：按预测概率算出的期望盈亏；
   - **倒计时**：距离到期的剩余时间；
   - 选 **1 周**期限时，结果卡会有显著的「**研究模式（非币安事件合约产品）**」标识——币安官方只有 10m/30m/1h/1d 四种，1 周是本系统的研究性延伸。
6. **到期后**：系统会用分钟级已收盘 K 线给出「研究估算」结果；你回系统在左栏对应报价上点「确认结算」（高于/低于/平价），录入真实结果。估算与真实结果分开统计，方便你长期检验这套方法靠不靠谱。

### 也可以：右下角 AI 助手

任何页面点右下角的机器人悬浮按钮，直接用人话描述问题（比如「BTC 永续现在是什么结构？还能追多吗？」），AI 会**自动识别场景并发起完整研究**，助手里的对话和研究终端是同一条会话：助手发起的研究可以点「在研究工作台」跳到研究终端看完整图表与证据。

窗口操作小贴士：机器人窗口可以点 ✕ 收起，收起后从右上角用户菜单里的「AI 助手」重新打开；窗口顶部有「历史」按钮翻过往对话、「✚ 新对话」开新话题。机器人按钮只有在管理员配置好 AI 后才会出现——一直看不到就是还没配置，找管理员。

## 三、背后的 AI Brooks 逻辑：三个场景的原理联动

这套系统的「大脑」是 Al Brooks 的价格行为学（Price Action）：不依赖指标堆砌，只读 K 线本身的结构。理解下面几个机制，你就能看懂 AI 每条建议「为什么这么给」。

### 3.1 共同底座：引擎是怎么「读图」的

**三层读法，从细到粗：**

| 层 | 读什么 | 类比 |
| --- | --- | --- |
| 单根特征 | 每根 K 线是趋势棒还是十字星、内包/外包（被前一根包住/包住前一根）等 | 认字 |
| 结构 | 摆动高低点、腿（一段段推动）、更高高点/更低低点、趋势还是震荡 | 组词成句 |
| 信号生命周期 | 形态成立（setup）→ 触发（如突破信号棒高点）→ 失效，三件事分开记录 | 成文 |

所以 AI 说「H2 二次进场」时，背后是一条完整链路：先确认在趋势中（结构层）→ 识别回调中的第二次顺趋势进场机会（H2 计数）→ 等价格突破信号棒高点才算**触发** → 并明确什么情况下这个信号**失效**。

**因果纪律（不穿越）**：引擎只用**已收盘**的 K 线，而且每个结构都带一个 `knownAt`（这个时间点你才能真正知道它）。摆动点可以画回它形成的位置，但系统做研究和回测时，严格只用当时已经能知道的信息——这保证了历史复盘不是「事后诸葛亮」。

**条件式结论，不是指令**：AI 给的不是「买！」，而是「如果价格突破 X，则结构支持做多；如果跌破 Y，则该判断失效」。每个结论都同时列**支持证据和反对证据**——有一个专门的「反证审查」环节负责唱反调，防止只看利多。

### 3.2 场景一联动：结构识别 + 知识库检索

现货场景的联动是「**引擎读图 + 知识库讲理**」：

- 引擎负责识别当前盘面的结构（什么状态、有哪些信号、各自成立/失效条件）；
- 知识库负责把 Brooks 原著里对应的**定义、成立条件、上下文、失效条件、易混淆概念**检索出来，引用精确到原文页码/图号，你可以点开核对。

所以场景一的回答总是在教你「为什么这么看」，而不是只甩给你一个方向。概念问答（「H2 是什么」）和盘面研究（「现在是什么结构」）走的是同一条链路。

### 3.3 场景二联动：结构定方向，代码算数值

永续场景在结构结论之上，叠加了你的持仓。这里有一条铁律——**各司其职**：

| 谁 | 负责什么 |
| --- | --- |
| Brooks 结构引擎 | 方向证据、关键价位（哪里是失效位/止损参考） |
| 代码（写死的公式） | 计划盈亏矩阵、手续费、资金费率情景、仓位上限 |
| AI（大模型） | 把上面两者组织成人话，列证据、给条件计划 |

**AI 不被允许编任何数字**。你看到的盈亏、费用、仓位上限全部由后端代码按公式计算，点数值可以溯源。同理，**强平价只显示你从 App 抄录的那个数**——没有你账户的保证金档位信息，任何「估算强平价」都是不负责任的，系统宁可不显示。

仓位上限的逻辑：用你填的「风险预算」（最多亏多少）除以「开仓价到止损/失效位的距离」，算出这笔单最多能开多大。这正是 Brooks 体系的核心思想——先定失效位，再定仓位。

### 3.4 场景三联动：结构证据 + 统计概率 + 期望值

事件合约场景多引入了一个角色：**统计预测模型**。理解它的三个要点：

1. **预测目标很精确**：预测的是「**到期那一刻**，价格相对**执行价**是高还是低」——不是「从现在起涨还是跌」。这两个问题完全不同：一张只剩 3 分钟的单子，不能套用「未来 10 分钟」的预测（系统对此有 20% 的期限匹配容差，不匹配就明确告诉你不可用）。
2. **概率不来自 AI 拍脑袋**：概率数字唯一来自统计预测模型（用历史数据训练的分位数梯度提升模型），Brooks 结构是它参考的证据之一。模型没训练好、期限没验证过、数据过期时，概率区域就是**空的并写明原因**——宁可说不知道，也不编数。
3. **值不值得买，代码说了算**：盈亏平衡胜率 = 投入 ÷ 总返还；期望净收益 EV = 赢的概率 × 净赚 − 输的概率 × 本金。只有当预测概率高于盈亏平衡胜率（EV 为正），这张单子在数学上才值得考虑。AI 负责解释，算术由代码完成。

### 3.5 一张表总结：三个场景怎么用同一个大脑

| | 现货结构研究 | USDT 永续 | 事件合约 |
| --- | --- | --- | --- |
| Brooks 结构引擎 | ✅ 识别结构 | ✅ 定方向与失效位 | ✅ 作为预测证据 |
| 知识库（Brooks 原文） | ✅ 概念讲解 | ✅ 规则依据 | ✅ 规则依据 |
| 代码数值计算 | — | ✅ 盈亏/费用/仓位上限 | ✅ EV/盈亏平衡胜率 |
| 统计预测概率 | — | — | ✅（未就绪则明确不可用） |
| 反证审查 | ✅ | ✅ | ✅ |
| 你提供的输入 | 一个问题 | 持仓数据 | App 报价数据 |

## 四、数据从哪来、有多新

所有行情数据都来自**币安官方公开接口**，不经过任何第三方转手：

| 数据 | 来源与更新方式 | 新鲜度 |
| --- | --- | --- |
| 实时价格（大盘总览、滚动行情条） | 币安 WebSocket 长连接，全市场每秒推送 | 秒级 |
| K 线（看盘页面） | REST 回补历史 + WebSocket 实时增量 | 实时 |
| 研究用 K 线（研究终端 / AI 助手） | 后台采集程序 7×24 常驻拉取币安最新数据入库（跟你开不开网页无关）；每次研究冻结当时快照 | 近实时，且**只用已收盘 K 线** |
| 资金费率、持仓量 | 币安永续合约公开接口 | 按币安自身周期（资金费率每 8 小时结算一次） |
| 事件合约报价 | **你从币安 App 手动抄录**（官方未开放接口） | 以你录入为准 |
| Brooks 知识库 | 管理员导入的 Brooks 官方资料 | 静态资料，引用精确到页码 |

为什么研究「只用已收盘 K 线」：正在走的那根 K 线还没定型，盘中信号会反复横跳。系统宁可等它收盘，也不用半截数据下结论——这是刻意的纪律（配合第三章的因果纪律），不是数据不新。实时价格会单独标注时间给你参考，但不会混进结构信号。

## 五、这些「异常」其实是正常的

系统设计原则是**宁可明说不知道，也不猜**。遇到下面几种状态不要慌：

| 界面表现 | 含义 | 你该怎么办 |
| --- | --- | --- |
| 顶栏行情时间标「数据陈旧」 | 行情数据停更或你网络断了 | 先看顶部连接状态；陈旧期间下的结论会打 stale 标，等恢复再问一次 |
| 概率一行显示「不可用」及原因 | 统计模型还在训练或该期限未验证 | 这是特性不是 bug——参考结构证据与盈亏平衡胜率，或换已就绪的期限 |
| 事件场景提示先录入报价 | 官方无接口，系统拿不到你的报价 | 按场景二/三的表单抄录 App 数据、在左栏选中后再问 |
| 结论卡显示「证据不足」（insufficient_evidence） | 校验器认为证据链不完整，拒绝给方向 | 按卡片列出的缺失项补充信息或换个问法 |
| 运行气泡状态显示 failed / cancelled（英文原词） | 运行出错 / 你主动点了取消 | 失败面板有「重新发起（相同标的与期限）」按钮，一键用相同条件重试 |
| 中栏 K 线停在过去某一刻不动 | 你正在回看历史研究，图表定格在当时的冻结快照 | 看完点图表区的「回到实时」按钮恢复 |
| 持仓行标「已过期需重确认」 | 持仓确认时间太久，不当当前事实用了 | 重新抄录/更新一次持仓（点「发起研究 / 录入」再保存一遍）再提问 |

## 六、常见问题 FAQ

**Q：网址打不开 / 一直跳登录页？**
A：先核对网址是 `https://btcpilot.duckdns.org/`（注意是 https）；跳登录页是正常的——输入账号密码即可。登录态 7 天有效，过期后系统会自动把你带回登录页，重登一次就行。

**Q：在国内能访问吗？**
A：不能。本服务仅面向海外地区开放，中国大陆来源的访问会被直接拦截（看到 403 提示页）。在海外但用的是国内手机运营商网络漫游时，如遇拦截请联系运营核实。

**Q：没有账号 / 忘记密码？**
A：系统不开放自助注册，联系发放网址的运营重置或新建账号。

**Q：为什么看不到「胜率 60%」这类数字？**
A：Brooks 的 H2≈60%、80% 等经验数字是他在**美股股指期货**上的统计，不能直接搬到加密市场。本系统只展示经过本品种数据验证的概率（统计模型输出），验证不了就显示不可用——这是刻意的纪律，不是功能缺失。

**Q：1 周期限为什么标着「研究模式」？**
A：币安官方事件合约只有 10 分钟/30 分钟/1 小时/1 天四种。1 周是本系统的研究性延伸预测，界面显著标注就是为了不和官方产品混淆。

**Q：系统会帮我下单吗？**
A：不会。它不连接任何交易账户，所有结论都是条件式研究意见（「如果…则…」），附带失效条件。买卖决策和实际操作永远在你手里。

**Q：手机上能用吗？**
A：可以。小屏下研究终端自动变成「图表 / 对话 / 证据」三个标签页，功能一致。

**Q：AI 助手和研究终端的对话是一回事吗？**
A：是。右下角助手和研究终端共用同一条会话，助手发起的研究可以一键跳到研究终端看完整图表与证据。
