# Biance Vision 用户操作手册 v3（对应 v0.16.x 界面）

> 适用版本：v0.16.2 及以上（2026-10-24）。线上入口：**https://btcpilot.duckdns.org**
> v3 相对 v2 的变化：知识库引用已接入研究回答（引用角标可点击、可跳原文）；AI 助手回答带可点击引用角标；其余基础操作与 v2 一致。
> 配套文档：管理后台见《admin-manual-v3.md》；价格行为复盘详见《brooks-price-action-manual.md》。

## 一、快速上手（3 分钟）

### 1.1 登录
1. 浏览器打开 https://btcpilot.duckdns.org —— 未登录会自动跳到登录页。
2. 输入账号、密码（由管理员开通，本系统不开放自助注册）。
3. 登录后进入「大盘总览」。会话 7 天有效，过期才需重新登录。

### 1.2 界面总览
- **顶部**：实时行情滚动条（BTC/ETH/BNB 快捷切换）+ 导航（大盘总览 / 价格行为 / 研究终端）+ 语言切换（中/EN）+ 账户菜单（退出登录）。
- **大盘总览页**：全市场涨跌统计、成交额排行、点击任意交易对看 K 线（按需自动订阅实时推送）。
- **右下角悬浮机器人**：AI 行情助手（见第四节）。

### 1.3 切换语言
右上角语言按钮即时切换中/英，全站文案（含 AI 回答语言偏好提示）跟随。

## 二、研究终端：三个典型场景（核心功能）

入口：导航「研究终端」。对话框式操作——用自然语言提问，系统自动识别意图（结构研究 / 永续持仓 / 事件合约 / 概念问答 / 新闻摘要）并走对应流程。

### 2.1 场景一：结构/概念研究 ——「现在是什么结构？H2 是什么意思？」
1. 直接输入问题，例如「现在 BTC 1h 是什么结构」或「铁丝网形态是什么」。
2. 概念类问题会检索**知识库**（Brooks 教学资料）作答，回答下方出现**引用角标**（v0.16 新增）：
   - 点击角标 `[1] 标题·第N页` → 展开该资料块的**原文片段**（冻结快照）。
   - 回答里的文本「来源」行同时保留（兼容旧形态）。
3. 结构研究会给出：当前结构判定、关键位、决策建议（等待/顺势/条件参与）。

### 2.2 场景二：USDT 永续持仓建议 ——「我的多单还能拿吗？」
1. 提问如「BTC 多单 0.01 还能拿吗」。
2. 若未录入持仓，系统弹出**持仓确认卡**：确认方向+数量（可补杠杆/开仓价）后继续。
3. 出**结果卡**：决策徽章（持有/减仓/退出…）→ 适用场景与时效 → 论断列表（每条带引用角标 `[n]`，点击展开证据原文）→ 概率与盈亏矩阵（含强平价、费用情景）。
4. 结果卡内的**证据角标**操作：
   - 点击 `[n]` 展开冻结原文；
   - 点「查看原文」→ 直接跳到该份资料的 PDF 对应页（受限资料会如实提示不可见）。

### 2.3 场景三：事件合约 EV ——「这张单值得买吗？」
1. 提问如「BTC 高于 60000 明天到期值得买吗」。
2. 系统取实时报价，出**事件结果卡**：EV（期望值）/ 盈亏平衡胜率 / 倒计时 / 建议参与或不参与。
3. 风险预算未确认时会先要求录入「单笔可承受损失」。

### 2.4 新闻/消息面 ——「今天有什么消息影响 BTC？」
自动抓取并核验新闻源，摘要回答附**网页引用角标**：点击展开摘要片段，「打开原页」直达原文链接（已核验）。

### 2.5 会话管理
- 左侧（或顶部）会话列表切换历史对话；上下文（交易对/周期/持仓）自动延续。
- 回答下方的翻译按钮可中英互译（离线引擎兜底，无需联网翻译服务）。
- 追问无需重述背景；对结果不满意可换一种问法重跑。

## 三、价格行为复盘（/brooks）

独立于研究终端的**手动复盘工具**：选交易对/周期 → 标注结构（趋势线、回调、H2/L2 等）→ 结合 AI 联动解释。详细操作见《brooks-price-action-manual.md》。

## 四、AI 行情助手（右下悬浮机器人）

- 点击机器人展开对话框，闲聊式提问（行情解读、知识问答）。
- **长期记忆**：助手会自动从对话中总结你的偏好（关注币种、风格），跨会话生效；
  - ` /remember 我主要做 SOL 短线` —— 手动写入一条记忆；
  - `/forget 风格` —— 删除含关键词的记忆；
  - 在面板里可查看/编辑/删除全部记忆。
- 助手回答若引用了知识库资料，同样带可点击引用角标。

## 五、常见问题

| 现象 | 说明 |
|---|---|
| 打不开网站 | 服务面向海外网络；大陆直连被区域策略拦截属预期（页面上会有说明） |
| 研究一直转圈 | 研究需 1-2 分钟（八步流程+实时行情校验），进度会逐步显示；长时间无响应可刷新后重试 |
| 引用角标点开说「定位可能失效」 | 该资料已更新重发布，引用的是冻结时的旧版本——内容仍可读，只是页码定位不再保证 |
| 提示「今日 AI 交互次数已达上限」 | 管理员设置了每日限额，次日自动重置 |
