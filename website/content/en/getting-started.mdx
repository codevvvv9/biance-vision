## 1. Get access

Start with the public demo. You do not need an account to explore how a conclusion, its evidence and its limits fit together. If the workflow fits your needs, contact us through the access page.

Access is currently enabled manually. We will discuss the intended use and access conditions before providing account instructions. No fixed price, free trial or response time is promised on this website.

## 2. Ask one focused question

After logging in, choose a research scene, a trading pair and a horizon. A useful first question is: “Review BTC’s current structure. Show supporting evidence, opposing evidence and the conditions that would change the conclusion.”

A question prepared on the website can be carried into the same browser tab for 30 minutes. This is a temporary handoff, not cloud storage. If you receive access the next day or use another device, simply type again or choose an editable example.

## 3. Confirm, then read

Review the question before sending. Choosing an example or logging in does not automatically start research. If an existing terminal draft is present, keep it or explicitly replace it.

Read the data time first, then the conclusion, supporting evidence, opposing evidence and invalidation conditions. A “wait” result can be useful; it tells you that the current evidence does not support a stronger conclusion.

## 4. If something is unavailable

Check the stated reason before retrying. Missing information may require an edited question or confirmed inputs. A service outage requires waiting for availability; repeated submissions cannot create missing evidence.

The terminal is a research tool. It does not connect a trading account, execute orders or guarantee an outcome.
